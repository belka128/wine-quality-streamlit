
# Wine Quality Prediction
Приложение прогнозирует вероятность хорошего вина по 12 признакам.

## Демо
https://wine-quality-belka128.streamlit.app/

## Запуск
Python 3.12.3
Из корневой папки проекта выполнить:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r wine_app/requirements.txt
streamlit run wine_app/app.py
```

Приложение откроется в http://localhost:8501.

## Возможности
- Оценка одного вина
- Метрики модели и графики
- Предсказания по CSV
- Анализ коэффициентов модели

## Файлы
- app.py - приложение
- model.joblib - обученная модель
- config.json - выбранный порог
- test.csv - тестовые данные
- requirements.txt - зависимости

## Кэширование
st.cache_resource используется для модели, потому что она должна загружаться один раз и использоваться повторно.
st.cache_data используется для таблиц и вероятностей, так как эти данные можно сохранять и повторно использовать.
Без кэширования joblib.load модель загружалась бы заново при каждом изменении порога, что замедляло бы приложение.
